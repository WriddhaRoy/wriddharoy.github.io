# Welcome

This is your first blog post! This blog is built with **Astro** and deployed on **GitHub Pages**.

## Features

- Minimalist design with Tailwind CSS
- Markdown-based content
- Admin dashboard for creating posts
- GitHub as CMS
- Fast and lightweight

## How to Create Posts

1. Navigate to `/admin`
2. Login with your GitHub Personal Access Token
3. Write your post in Markdown
4. Click "Publish Post"

The post will be committed to your repository, triggering a rebuild of the site.

## Markdown Support

You can use all standard Markdown features:

- **Bold text**
- *Italic text*
- [Links](https://example.com)
- Lists
- Code blocks
- And more!

Happy blogging! ✨
